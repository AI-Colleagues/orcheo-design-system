# AI Colleagues — marketing site UI kit

Hi-fi recreation of the **AI Colleagues** corporate marketing site, introducing the Orcheo product.
A single scrolling landing page composing the design-system primitives (Button, Badge, NodeChip, Tag).

## Run it
Open `index.html`. Loads `styles.css`, the compiled `_ds_bundle.js`, the icon set, and `site.jsx`.

## Files
- `index.html` — entry; mounts `window.AICSite`.
- `site.css` — section/layout styles (nav, hero, features, footer). Controls come from the DS.
- `site.jsx` — all sections (Nav, Hero + product mock, Logos, Features, Steps, Stats, CTA, Footer).
- `icons.jsx` — Lucide-style icon set (copied from the Orcheo app kit).

## Sections
Sticky nav · hero with a live product mock (NodeChip canvas) · trusted-by logo strip · feature grid ·
how-it-works steps (cream section) · stats band (ink section) · orange CTA · footer.

## Notes
- Corporate voice + ink anchor for AIC; orange + the orchestration mock for the Orcheo product.
- Copy follows the brand content fundamentals (sentence case, verb-first, no emoji).
- Company names in the logo strip are placeholders.
