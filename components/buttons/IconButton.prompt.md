Compact button holding a single icon — toolbars, canvas controls, card actions. Always pass an accessible `label`.

```jsx
<IconButton label="Run" variant="solid"><PlayIcon/></IconButton>
<IconButton label="More" variant="ghost"><MoreIcon/></IconButton>
<IconButton label="Settings" variant="outline" round><GearIcon/></IconButton>
```

Variants `ghost | solid | outline`; sizes `sm | md | lg`; `round` for circular.
